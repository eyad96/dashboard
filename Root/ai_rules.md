# قوانين المطور المساعد (AI Agent Rules)

1. الالتزام بالتقنيات: Next.js (App Router), TypeScript, Tailwind CSS.
2. قبل إغلاق أي مهمة، يجب تشغيل الأوامر التالية والـتأكد من عدم وجود أخطاء:
   - `npm run lint`
   - `npm run build`
3. الالتزام التام بالمرحلة الحالية المحددة لك، وممنوع تعديل ملفات خارج نطاقها.
4. عند إنهاء المرحلة، قم بتحديث ملف `project_status.md` بالتغييرات، ثم قم بعمل Git Commit واضح.
